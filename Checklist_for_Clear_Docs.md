# ✅ Sae Ra's Checklist for Clear Docs

Use this checklist every time you create or review documentation to ensure it's clear, useful, and maintainable.

---

## 📌 Before You Start
- [ ] Do I know who the audience is?
- [ ] Is the purpose of this document clear?
- [ ] Have I chosen the right format (guide or FAQ)?

---

## ✍️ Writing & Structure
- [ ] Title is clear and descriptive
- [ ] Intro briefly explains what the doc covers
- [ ] Steps are listed in a logical order
- [ ] Headings and subheadings are used consistently
- [ ] Sentences are short and direct
- [ ] Avoided jargon or explained it clearly

---

## 🖼 Visuals
- [ ] Screenshots are relevant and up to date
- [ ] Images have helpful annotations (arrows, highlights)
- [ ] Screen recordings are short and to the point
- [ ] Visuals are placed near the related step

---

## 🔗 Formatting & Markdown
- [ ] Used bullet points or numbered lists where appropriate
- [ ] Code or commands are in code blocks
- [ ] Links are clearly labeled (no "click here")
- [ ] Used Obsidian callouts for notes/warnings if needed

---

## 🔄 Review & Maintenance
- [ ] Someone else has reviewed it for clarity
- [ ] Last updated date is listed
- [ ] File is saved in the correct location or system
- [ ] Is it easy for others to find or search for this document?

---

Keep this checklist handy as a reference for writing high-quality documentation. A little effort upfront = hours saved later!
